# Dragon Shop AI

Интерфейс из исходного `Сайт.html` объединён с поиском товаров и настоящим AI-помощником. Итоговая страница — `Сайт.html`.

## Запуск

1. Установите зависимости: `pip install -r requirements.txt`
2. В том же терминале задайте секретный ключ OpenAI:

   ```powershell
   $env:OPENAI_API_KEY="ваш_ключ"
   ```

   При необходимости можно выбрать другую модель: `$env:OPENAI_MODEL="gpt-5.2"`.
3. Запустите API: `uvicorn main:app --reload`
4. Откройте `Сайт.html` в браузере.

Страница отправляет запросы на `http://localhost:8000/search` и `http://localhost:8000/chat`. Ключ не попадает в браузер: он используется только сервером. История последних 12 сообщений передаётся для контекста текущего диалога, а ответы OpenAI не сохраняются через API (`store=False`).

Сейчас поиск возвращает тестовые товары; функцию `mock_search` в `main.py` нужно заменить интеграцией с реальным поставщиком, когда она будет готова.
